`main.py` (Python 3.13, standard library only) writes one line — a robot
vacuum's deadpan excuse for missing a spot — to `/output/entry.txt`.

> I mapped the crumb as a load-bearing structure and built my route around it. Removing it now would compromise the floor plan.

Run it with:

```sh
python3 -P -s main.py
```
